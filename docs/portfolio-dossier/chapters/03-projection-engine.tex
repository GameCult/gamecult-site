\chapter{Projection Engine}

The projections in this dossier are deliberately loud. Timid projections teach nobody anything. The discipline is that every loud number must name the proof required.

\section{Scenario grammar}

\ProjectionBand
{Internal survival: the project makes GameCult faster, clearer, or less dependent on private memory.}
{Product wedge: outsiders adopt the project for one painful workflow.}
{Platform spread: the project becomes part of the shared CultMesh/Bifrost/Eve substrate.}
{The claim fails because the project cannot produce external repeatability, governance trust, or low-friction adoption.}

\section{Value bands}

\ValueLadder
{Saves enough labor to justify its maintenance.}
{Creates a saleable product or patron-supported project surface.}
{Becomes substrate for multiple GameCult and external participants.}
{Changes how online work, games, or operational interfaces coordinate.}

These are not valuations. They are pressure gauges. If a project wants a bigger claim, it owes a bigger receipt.
