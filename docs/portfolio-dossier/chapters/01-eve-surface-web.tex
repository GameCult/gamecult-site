\section{CultUI semantics}

A surface should describe meaning, not smuggle executable UI:

\begin{itemize}
  \item stable widget ids
  \item typed bindings
  \item command routes
  \item layout intent
  \item permission hints
  \item health and provenance
  \item local renderer affordances
\end{itemize}

Web can render it as DOM. Desktop can render it as native controls. Mobile can render it as touch-first panels. Unity can render it as runtime UI. Sai can render it as a story room.

\Verdict{If Eve streams arbitrary DOM, we built remote desktop with better incense. If Eve streams CultUI surfaces, we built a new public interface grammar. Choose the second thing.}
