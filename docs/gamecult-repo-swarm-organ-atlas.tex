\section{Prime Shape}

GameCult is a repo swarm, not a product list. The useful question is not
``which repository is exciting this week?'' The useful question is which organ
owns which truth, what typed state it emits, and which neighboring organs become
more capable because it exists.

\Verdict{The coherent machine is a loop: agents act through Epiphany and VoidBot;
state persists through CultCache and travels through CultNet and CultMesh; Odin
discovers the Verse; Eve lowers provider-owned interfaces; Weksa and AquaSynth
make culture speak; games, worlds, creator tools, and public sites keep the
whole system honest by making it touch people.}

\section{Core Harness and Persona Agents}

\subsection{Epiphany}

\Signal{Role:} core harness. Epiphany is the repo and agent work body where
models are expected to understand the machine they touch. It pressures work
through body maps, authority maps, persistent memory, and verification instead
of letting every task become a confident little cliff dive.

\begin{itemize}
  \item Owns: agent harness behavior, work execution posture, Persona-state schema pressure, verification discipline.
  \item Feeds: VoidBot, repo Faces, Ghostlight, the public Persona system, and any future worker that needs memory with spine.
  \item Needs: CultCache for durable state, CultNet and CultMesh for typed crossings, Eve for inspection surfaces.
\end{itemize}

\subsection{VoidBot}

\Signal{Role:} running precursor. VoidBot is the Discord-native proving ground
for Persona agents with persistent state. It searches archives, indexed repos,
and lore, speaks through room surfaces, and hands deeper work off to heavier
tools when the room needs more than chat.

\begin{itemize}
  \item Owns: Discord-native retrieval, room memory, repo source search, owner notification compatibility, live Persona pressure.
  \item Feeds: Epiphany's design lessons, Ghostlight social continuity, Bifrost crossing patterns, repo-Face state.
  \item Demotion line: delivery mechanisms are actuators, not sovereign truth. Bifrost should own public and owner-facing crossings when those crossings become formal.
\end{itemize}

\subsection{Ghostlight and EpiphanyAquarium}

Ghostlight carries persistent social state for characters, agents, and Faces.
EpiphanyAquarium, EpiphanyAquarium-Bevy, EpiphanyAquarium-Web, and
Aquarium-Engine are the visual and runtime labs for agent ecology,
self-modeling, and character surfaces.

\begin{itemize}
  \item Ghostlight owns social continuity and character state pressure.
  \item EpiphanyAquarium owns the aquarium metaphor made inspectable: visible agent ecology, not hidden prompt soup.
  \item The Bevy and Web bodies prove that the same agent ecology can be lowered into different runtimes.
\end{itemize}

\section{Substrate, Protocol, and Mesh}

\subsection{CultLib, CultCache, CultNet, and CultMesh}

CultLib is the nervous system family. Its job is to make state, protocol, and
cross-runtime behavior boring enough that the exciting layers stop using local
folklore as infrastructure.

\begin{itemize}
  \item \Term{CultCache} persists typed state in cache files. It is the durable memory substrate.
  \item \Term{CultNet} carries typed communication between peers and services.
  \item \Term{CultMesh} networks daemons, state catalogs, discovery, schema surfaces, and provider-owned interfaces.
  \item \Term{CultLib} is the reference family and shared runtime pressure that keeps the ports aligned.
\end{itemize}

\section{Verse Sight, Keepalive, Identity, and Crossings}

\subsection{Odin, Gjallar, and Idunn}

Odin is the all-seer. It accepts Verse discovery, schema catalogs, translation
routes, provider surfaces, and observation projections. It preserves provider
ownership: Odin sees truth that other daemons deliberately publish; it does not
replace those daemons with a secret central registry.

\begin{itemize}
  \item \Term{Odin} owns accepted Verse sight, schema awareness, translation planning, and interface aggregation.
  \item \Term{Gjallar} presents a composite of Odin's sight. It owns overview composition, not provider truth and not terminal glyph rendering.
  \item \Term{Idunn} keeps the daemons alive. It reads Odin's accepted map, watches health, performs restart intent, and escalates operator-needed failures through the right crossing.
\end{itemize}

\subsection{Heimdall and Bifrost}

Heimdall owns identity, grants, claims, consent, revocation, and gatekeeping
boundaries. Bifrost owns crossings: patronage, work records, receipts, motions,
operator notifications, and owner/public routes where an action must become
accountable typed state.

\begin{itemize}
  \item Heimdall protects who may act.
  \item Bifrost records why the action is legitimate, who requested it, what happened, and where the receipt lives.
  \item Odin may see these surfaces, Eve may lower them, but neither becomes their owner.
\end{itemize}

\section{Interfaces, CultUI, and Public Projection}

\subsection{Eve}

Eve is daemon dashboard lowering. A daemon publishes an Eve UI DSL composition,
also called CultUI. Eve lowers that composition into GUI, TUI, browser, native,
overlay, or future room surfaces.

\Verdict{The renderer does not become truth because it has pixels. The daemon
owns the interface composition. Eve lowers it. Odin discovers it. Gjallar may
summarize it. That authority split is the difference between a dashboard and a
little state monarchy with a nice font.}

\section{Language, Voice, and Alien Culture}

\subsection{Weksa}

Weksa is the language engine. It lowers utterance intent through arbitrary
linguistic, cultural, and personal ontologies into words. The important part is
not vocabulary generation. The important part is that meaning passes through a
culture and a speaker model before it becomes language.

\subsection{AquaSynth}

AquaSynth is the voice, both instrumental and tracheal. It can take Weksa's
utterance embeddings and realize them through arbitrary vocal morphologies.
aquasynth-rs is the lower-level Rust body for pushing the sound machinery closer
to daemon and runtime use.

\subsection{Combined Capability}

Together Weksa and AquaSynth let GameCult create alien languages embedded in
their native cultures and then hear those languages spoken by bodies that do
not need to be human. The pipeline is:

\begin{enumerate}
  \item Culture and speaker state constrain intent.
  \item Weksa lowers intent through ontology and grammar.
  \item AquaSynth maps the utterance into a vocal morphology.
  \item Eve, Sai, games, streams, or worlds present the result to people.
\end{enumerate}

\section{Design Rule}

Each organ should be defended in one sentence:

\begin{quote}
\textbf{X owns Y so that Z remains true.}
\end{quote}

If the sentence sounds false, awkward, or suspiciously padded, the organ is not
yet coherent. Fold it into the right owner, split the hidden responsibility, or
cut the dead authority. The swarm does not need more little thrones. It needs
clean nerves.
