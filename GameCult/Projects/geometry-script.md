# geometry-script

*"Not a GameCult-authored product so much as a fork someone wanted close at hand for future trouble."*

`geometry-script` is a public fork of Carson Katri's Geometry Script project for Blender Geometry Nodes. It is not a repo with a long internal GameCult development arc. It is a dependency-adjacent fork parked inside the org because procedural geometry, scripting workflows, and toolchain control were relevant enough to justify keeping a local handle on the code.

## Founding Idea

The founding idea was not "let's build a brand-new geometry tool from scratch." It was "this upstream tool matters enough that we want a fork under the org, either to study it, patch it, or keep it close if it becomes part of the broader pipeline."

## Trajectory

The public repo does not show meaningful GameCult-native divergence yet. Its value is positional. The act of forking it into the org is the interesting move, not the still-empty list of follow-up commits.

## Ambition

If this repo becomes important later, it will be because procedural geometry starts feeding art generation, pipeline tooling, or environment construction somewhere else in the studio stack. Right now it reads as deliberate preparedness rather than a declared flagship effort, which is a perfectly respectable thing for a fork to be.
