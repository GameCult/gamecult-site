# Epiphany

*"A coding harness built on the rude suggestion that coherence should survive longer than one reply."*

Epiphany is the public GameCult fork of Codex turned into a more opinionated control system. It is trying to drag important state out of transcript fog and into typed, inspectable surfaces: maps, evidence, retrieval, bounded reflections, replay, churn pressure, verifier seams, and the broader machinery required to stop a model from making plausible local moves after the global design has already quietly wandered off and died in a ditch.

## Founding Idea

The founding idea is refreshingly hostile to magic. The model must model the thing it is changing. If it cannot maintain a live map of architecture, evidence, freshness, and pressure, then all the nice local edits in the world still amount to a machine confidently building a Jenga tower and calling it understanding.

## Trajectory

The public history is young and already weirdly specific. The README spells out the larger architectural argument: typed state, rollout snapshots, bounded reflection, verifier promotion, explicit launch authority, and durable checkpointing. The recent commit wave tells you where the repo is currently metabolizing that argument: startup birth valves, heartbeat physiology, memory distillation, repo-owned organs, and the small matter of turning "agentic coding" into a maintained system instead of a faith-based exercise.

This is not a repo trying to be charming about it. It is trying to become inspectable.

## Ambition

The ambition is not merely "better code generation." It is a control system for coding agents: source modeling, coherence maintenance, evidence banking, bounded delegation, verification, reorientation, and eventually enough architectural self-awareness that the machine can stop eating its own context every time the repo gets large.
