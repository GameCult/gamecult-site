# EpiphanyAquarium

*"The operator surface for Epiphany, because apparently the command line was not wet enough."*

EpiphanyAquarium is the fullscreen interface layer for Epiphany: React, Tauri, WebGL2, fluid simulation, local option petals, focus surfaces, and interaction audio. It exists so the harness can develop an actual operator-facing body instead of forcing every coordination decision to arrive wearing terminal clothes.

## Founding Idea

The founding idea is that orchestration should be visible, local, and tactile instead of buried inside an endless chat transcript. If Epiphany is the machine mind, Aquarium is the glass tank, the control petals, the focus surfaces, the glowy little lie that this all feels natural.

## Trajectory

The repo begins with the operator-surface thesis already in place, then immediately starts fussing over the parts that make an interface feel alive rather than merely informative: modular synth control lanes, sfxr patch golf, readability metrics, wobble bass, FM bells, 808 targets, script compiler abstractions. Which is to say the public history looks half like UI work and half like somebody refusing to let the interface sound dead.

That is not ornamental drift. It is the repo making a case that the operator surface deserves its own taste.

## Ambition

The ambition is a live control room for agent systems that does not flatten everything into menus and status text. Local object interaction, inspectable state, bounded affordances, swarms that message each other visibly, and enough sensory feedback that the surface feels like a system instead of a spreadsheet reluctantly cosplaying as one.
